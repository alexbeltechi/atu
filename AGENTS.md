# Working on ATU

Start with [README.md](README.md). ATU is in exploratory mode. Nothing in `strategy/positioning.md` is a final brand statement or an approved commercial offer.

## What to read

- Researching people / references / opportunities → `research/people-and-prospects.md`
- Comparing providers / defining a distinct position → `research/landscape-and-competitors.md` and `strategy/positioning.md`
- Generating posts / developing editorial voice → `content/README.md`, `content/idea-bank.md`
- Designing Figma / Parabola reusable social templates → `content/formats-and-moodboard.md`
- Updating the brand map → `strategy/positioning-map.svg` and its explanation

The canonical personal project history and corrections are in the **private** `alexbeltechi/beltechi-brain/projects/atu/`; authorized collaborators should consult them if available. Never copy private Brain content into this public repo.

## Rules

- Facts about people or services: attach direct public source links and date checked.
- Mark observations and ATU hypotheses as such; never present a public person as a confirmed prospect without evidence.
- Distinguish examples created for a fictional persona from quotes or experiences attributed to a real subject.
- Romanian copy should sound natural, direct, and not overly flattering or “coachy.”
- Public editorial focus first, minimal business-card website later, commercial offer only after clearer validation.
- Do not build or publish a website, post on social media, contact people, or spend money without explicit instructions.
- Keep existing file paths stable so mood boards, agents and future docs can link to them.
